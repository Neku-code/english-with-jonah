# Jonah illustration assets

Generated for the English with Jonah student redesign on 2026-10-19 using the built-in `image_gen` tool. These original illustrations use the user's supplied dashboard image as visual direction (warm cream, terracotta, sage, and an illustrated Uzbek learning setting). No third-party stock assets or fonts are embedded. No reference image was sent to the generation calls.

The PNG originals remain in the session's generated-image output. The project files are optimized WebP copies; only resizing and format conversion were performed with Pillow, without cropping, compositing, or repainting.
